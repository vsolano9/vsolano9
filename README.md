# Victor

I build iPhone apps and small tools for the boring parts of shipping.

Owned public repos: [metaproof](https://github.com/vsolano9/metaproof) and [screenproof](https://github.com/vsolano9/screenproof), a zero-dependency App Store submission-preflight pair for fastlane `deliver` folders. metaproof lints the text metadata (required fields, field lengths, keywords, descriptions); screenproof lints screenshots and app preview videos against Apple's upload limits. Both are on npm and ship as GitHub Actions.

First merged contribution: [getsentry/XcodeBuildMCP #456](https://github.com/getsentry/XcodeBuildMCP/pull/456), test coverage for SwiftUI tab identifier surfacing. Merged July 2026, so now I count it. Current total: 33 merged contributions across 11 upstream repositories.
